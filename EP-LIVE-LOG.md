# Registro histórico retirado

Este archivo dejó de ser un registro operativo público. Entorno Persistente Medio v1.0 conserva eventos en la bitácora remota autenticada de Khora. Un token efímero de sesión permite consultar `GET /api/ep/logs?which=current` y `GET /api/ep/logs?which=last`.

La especificación normativa única es [`ep-medio-architectura.md`](./ep-medio-architectura.md).
