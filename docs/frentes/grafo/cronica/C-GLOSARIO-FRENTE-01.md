### 3. Unidades y distinciones operativas

| Término | Significado |
|---|---|
| **Fuente y versión** | El material de origen y el corte concreto del que procede una interpretación. |
| **Unidad de sentido** | Fragmento con contexto suficiente para comprender lo expresado; no necesariamente una oración. |
| **Ocurrencia** | Una aparición concreta de una idea o afirmación en una fuente. Repetirla después constituye otra ocurrencia. |
| **Ancla / afirmación anclada** | Referencia verificable a una fuente concreta / afirmación vinculada a las fuentes que la sostienen. Tener ancla no demuestra por sí solo que la interpretación sea correcta. |
| **Relación** | Vínculo entre elementos del grafo cuyo significado y fundamento deben poder examinarse. Identidad, afinidad, causalidad y simple coaparición no son equivalentes. |
| **Comunidad de Leiden** | Agrupación obtenida del grafo suministrado al algoritmo. Es un resultado derivado, no una categoría natural indiscutible ni un diagnóstico personal. |
| **Juicio del operador** | Tu acto explícito de ratificar, rechazar o revocar una propuesta; no se deduce del silencio ni de una aceptación automática. |
| **Premisa / inferencia** | Punto de partida utilizado en un razonamiento / conclusión obtenida a partir de él. Deben conservarse diferenciados y con su estatuto, sin convertir una hipótesis en hecho por almacenarla. |

Las unidades y los estados deben permanecer separados: **procesado no significa fiel; tener fuente no significa verdad externa; aceptación automática no significa ratificación tuya**.[^https://github.com/SeryMente/khora/blob/fix/graph-occurrence-history-20261018/khora-web/docs/GRAPH-QUALITY-DRAFT.md]
