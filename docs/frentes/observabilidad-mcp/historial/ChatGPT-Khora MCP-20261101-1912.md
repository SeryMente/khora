# 4. Comprensión del sistema KHORA MCP

## 4.1. Propósito global

KHORA MCP es la interfaz programática única mediante la cual los clientes, modelos y agentes compatibles y autorizados pueden descubrir y utilizar las capacidades que Khora expone.

El alcance general comprende:

- Herramientas y operaciones.
- Recursos, cuando estén efectivamente implementados.
- Prompts e instrucciones especializadas.
- Catálogo y descubrimiento.
- Contratos de entrada y salida.
- Endpoint y transporte.
- Autenticación y autorización.
- Scopes y permisos por recurso.
- Interoperabilidad entre clientes y entornos.
- Observabilidad y diagnóstico.
- Trazabilidad y seguridad.
- Versionado, pruebas y evolución del servidor.

La observabilidad y Jules son facetas del frente, no su propósito completo.

El objetivo estratégico original es que los modelos autorizados puedan acceder a los registros de observabilidad con suficiente riqueza, contexto y trazabilidad para diagnosticar problemas concretos y determinar soluciones con evidencia.

Un caso de uso inicial es el diagnóstico de problemas relacionados con Dictado. Sin embargo, KHORA MCP no debe quedar limitado a Dictado.

El alcance deseado no demuestra que todas las capacidades estén desplegadas. Para acreditar su disponibilidad debes inspeccionar el código, el catálogo real, los permisos efectivos y las respuestas de los clientes.
