# Salida · regla de aceptación local de Harmonia

Se conserva la instrucción del operador como criterio de aceptación permanente: **la prueba local la realiza el operador usando el sistema; el asistente se encarga de todo lo demás**. Las pruebas headless/sintéticas son controles de ingeniería, nunca aceptación funcional.

Estado de este ciclo: regla pendiente de integrar en OCP v0.29; paquete físico y sincronización RDC no confirmados; Chrome no manipulado; E2E continúa abierta.
