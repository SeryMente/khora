# Banco local ejecutado C031
Estos son los programas exactos del banco aislado, no un runner productivo ni prueba de producción. Usaron /data/khora-ingreso-c031/verify/repo (enlace a integrated), esbuild0.25.12, React19.2, Playwright1.56.1, Chromium resuelto por which, Node24, TypeScript5.9.3 y PGlite0.5.10. La aplicación declara React19.1; full build remoto conserva sus dependencias reales. Las rutas absolutas conservan la procedencia del ensayo; para reproducir en otro equipo deben montarse o adaptarse explícitamente, sin confundir adaptación con ensayo ya ejecutado. Los adaptadores de auth, normativa, cifrado/proveedores/red se identifican en cada programa. No contienen secretos ni datos del operador. No confundir fixture HTTP con despliegue.
