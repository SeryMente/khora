# Intervalo sonoro · Splash v1

Operator approved option 01 of the ten-direction study, 2026-10-17.
Source: https://app.notion.com/p/7395d4a3b2508232a6bc81af030b38dd
Baseline splash contract: https://app.notion.com/p/a345d4a3b250830291e881d8f76e993c

Six rounded bars form mirrored fields around an interval. Exactly one interior bar
has a negative diagonal cut. Khora remains Geist 600, below the mark with a 24px gap.
The whole lockup is centered. Palette, 1200ms timeline, 500ms reduced motion,
font deadline, immediate skip and cold-boot-only lifecycle remain unchanged.

54 instances = 3 height profiles × 3 gaps × 2 cut sides × 3 cut heights.
A local Uint32 cosmetic seed selects once before reveal, with canonical fallback 0.
No network, storage, user data, telemetry, service or continuous morphing is added.
Repeated instances are expected. The Intérprete namespace is semantic, not encryption;
multilingual lettering, favicon, app icons and other subbrands remain out of scope.

The grammar is pure and exhaustively unit tested; browser tests cover deterministic
seed selection, entropy fallback, stability, both themes, four viewport sizes,
geometry, raster baselines, skips, font failures and timing. Snapshot updates require
visual inspection; they must not be used to approve an unintended design change.
