Six rounded bars form mirrored fields around an interval. Exactly one interior bar
has a negative diagonal cut. Khora remains Geist 600, below the mark with a 24px gap.
The whole lockup is centered. Palette, 1200ms timeline, 500ms reduced motion,
font deadline, immediate skip and cold-boot-only lifecycle remain unchanged.

54 instances = 3 height profiles × 3 gaps × 2 cut sides × 3 cut heights.
A local Uint32 cosmetic seed selects once before reveal, with canonical fallback 0.
No network, storage, user data, telemetry, service or continuous morphing is added.
Repeated instances are expected. The Intérprete namespace is semantic, not encryption;
multilingual lettering, favicon, app icons and other subbrands remain out of scope.

The grammar is pure and exhaustively unit tested; browser tests cover deterministic
seed selection, entropy fallback, stability, both themes, four viewport sizes,
geometry, raster baselines, skips, font failures and timing. Snapshot updates require
visual inspection; they must not be used to approve an unintended design change.

## Active delivery amendment · 2026-10-19

Operator requested professional lifecycle refinement, secondary waiting identity,
OpenID Connect sign-in redesign and favicon, with documentation, integrated testing
and production delivery. This extends the October 17 scope; it does not redesign
the six-bar grammar, authentication provider, session policy or app-install icons.

- Cold document navigation may present the identity; reload, history restoration,
  same-origin return and technical/auth handoff do not. No elapsed-time/30-minute
  replay rule. Client navigation and visibility changes do not restart it.
- The 1200ms normal / 500ms reduced-motion limits include the local font wait after
  hydration. Missing font, hidden page, failed animation and omitted presentation
  release access immediately. A prepaint watchdog releases a non-hydrating SSR
  overlay after 2500ms. Disabled JavaScript cannot remain behind the overlay.
- A one-use sessionStorage cosmetic handoff flag prevents auth/technical return
  from becoming another welcome. Denied storage is handled; it is never an auth flag.
- One bounded cosmetic variant per document; no user data, network generator or
  continuous motion. Local waits appear only after 300ms and disclose a prolonged
  wait at 8 seconds, without fake progress. Preserve existing content and actions.
  Route loading and Consulta response waiting use the secondary mark; button-level
  spinners, skeletons and other useful controls are not replaced indiscriminately.
- Sign-in: restrained shared brand, clear heading and action, visible focus, pending
  state preventing duplicate submission, generic error without raw provider details,
  mobile/desktop, existing themes. OIDC configuration and server action are retained.
- Favicon: static canonical instance in a square, not randomized between renders.
  Exactly the two SVG icon routes are public; protected neighboring paths remain
  under the existing middleware. App-install images are unchanged.
