# Instanciación privada

1. Autentícate mediante Google OpenID Connect en `/sistema/entorno-persistente`.
2. Genera un token Khora nuevo para la sesión.
3. Copia el comando, pégalo sin ejecutarlo, copia el token y después presiona Enter.
4. El gate obtiene la llave de bóveda, valida un Personal Access Token de GitHub para `SeryMente/khora` privado y continúa con Vercel.

`llave/ARRANCAR.cmd` existe solo para mantenimiento desde una copia ya autorizada. La especificación normativa es [`ep-medio-architectura.md`](./ep-medio-architectura.md).
